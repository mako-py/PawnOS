# PawnOS

* A minimal Debian-based operating system heavily focused on user choice.

## What is PawnOS?

PawnOS is an operating system that is designed to give the user a starting point.

It doesn't have anything special to it like Kali Linux, ParrotOS, or BlackArch.
Instead, it's a base that the user can build upon and shape.

## Why PawnOS?

PawnOS is really just a small project. It's not that good in its current state, but I'm actively trying to make it better.

It is also so I can understand Linux more. :)

## Who is PawnOS for?

It's for anyone, really. But I suppose it's for people that want a more minimal operating system.

## When did PawnOS start?

PawnOS started around 2026, but I've had previous attempts.

Yet, I've been interested in Linux since about November 2025.

## Where does the name come from?

The name "PawnOS" comes from chess.

A pawn starts with a simple role and limited movement, but it can eventually become a queen, rook, bishop, or knight.

PawnOS follows the same idea. May be nothing, but can become everything.
